# Dashboard UI - Figma Implementation

A responsive dashboard application built with React and TypeScript based on the provided Figma design.

## Overview

This project implements the assigned dashboard screens from the Figma design with a focus on:

- Pixel-focused UI implementation
- Responsive layouts
- Reusable React components
- Client-side navigation
- Frontend interactions
- Clean and maintainable code

## Screens

The current scope includes the completed Dashboard and the Products page. Orders and Customers are reserved routes for future work and do not have screens yet.

## Features

### Dashboard

- Revenue overview
- KPI summary cards
- Sales by channel
- Date range selection
- Export functionality

### Products

- Product listing with status and category filters
- Search and selection actions
- Add new product functionality

## Responsive Design

The dashboard is designed to work across:

- Desktop
- Tablet
- Mobile

The layout adapts for smaller screens while maintaining usability and visual consistency with the Figma design.

## Frontend Interactions

The application includes frontend-only interactions such as:

- Client-side page navigation
- Add Customer
- Add Product
- Export data
- Date/history selection
- Filters and dropdowns
- Responsive sidebar/navigation

The project currently uses frontend/mock data and does not require a backend API.

## Tech Stack

- React

- Vite
- React Router
- CSS
- JavaScript/TypeScript
